# Happiness Dashboard

A Chrome new-tab page with a greeting, a daily compliment, Unsplash wallpapers on themes you pick, and quick bookmark search.

### For development

- Copy `src/keys.example.js` to `src/keys.ignore.js` (that file is gitignored) and set `unsplashApiKey` to an [Unsplash](https://unsplash.com/developers) access key
- Run `yarn run watch` in the terminal
- In browser extensions, load the unpacked `dist` folder at [chrome://extensions/](chrome://extensions/)

### This extension is published at

For Google Chrome: https://chrome.google.com/webstore/detail/happiness-dashboard/oneanpfkjoecldedcopalhkhneiehggo
